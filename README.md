# CZ 75 B 交互式 3D 可视化模型

本项目是一个基于 Three.js 构建的 CZ 75 B 手枪 3D 可视化与交互动画演示。通过纯代码程序化建模，还原了枪械的 14 个主要外观组件，并提供丰富的交互操作与动画效果。

## 📖 使用方式

- 使用 **Chrome** 或 **Edge** 浏览器打开 `index.html`。
- **无需安装任何依赖，无需联网**（Three.js r160 已包含于本地 `vendor/three.min.js`）。

## 🖱️ 操作说明

- **视角控制**：拖动旋转、滚轮缩放、支持自动旋转。
- **组件交互**：悬浮组件显示标签；点击标签或右侧索引平滑聚焦并弹出介绍。
- **磨损调节**：拖动滑动条，可观察亮色划痕、涂层剥落与暗哑污渍。超过 35% 后，主体逐步出现凹陷和轻微弯曲；回到 0% 恢复原始表面与几何。磨损位置固定，不随视角或动画跳动。
- **光照与亮度**：使用离线生成的 HDR 摄影棚环境，经 PMREM 预过滤产生与粗糙度对应的环境反射；配合主光、补光、轮廓光及 2048 阴影。右上角“画面亮度”可调整曝光。
- **动画演示**：支持开火、换弹、拆卸和组装动画。
- **复位功能**：点击“恢复侧视”可中断当前动画并复位模型。

## 🔫 模型组件 (共 14 个独立组件组)

1. 准星 (Front sight)
2. 滑套 (Slide)
3. 滑套卡榫/分解闩 (Slide release / Takedown latch)
4. 照门 (Rear sight)
5. 击锤 (Hammer)
6. 手动保险 (Thumb safety)
7. 复进簧导杆 (Recoil spring rod)
8. 枪体 (Frame)
9. 扳机护弓 (Trigger guard)
10. 扳机 (Trigger)
11. 弹匣卡榫 (Magazine catch)
12. 握背 (Backstrap)
13. 握柄 (Grip)
14. 弹匣 (Magazine)

### 额外细节
模型额外包含了枪口、枪管外观、滑套刻字与防滑槽、握柄纹理以及固定螺钉。

## ⚠️ 注意事项

- 参考图片仅提供单侧外观。本作品是**可视化外观重建**，不能保证看不到的内部零件或另一侧细节与实物一致。
- 分解动画是展示性的空间位移，**不代表实际拆装步骤**。
- 开火和换弹动画仅为外观演示，**不模拟弹道或真实机械工作过程**。
- 开火、换弹动画需要模型处于**组装状态**下才可执行。

## 代码与验证

- `app.js` 已展开格式，并按场景、模型构建、组件交互、磨损和帧更新分段。
- 枪体采用 `MeshPhysicalMaterial`，使用基于 GGX 的物理反射、金属度与粗糙度工作流及保护层反射。颜色和 HDR 辐射在线性空间参与照明，再经 ACES 色调映射输出 sRGB。高金属度表面由环境反射补充照明。
- 磨损会改变底材、污渍的反光及保护层覆盖。GPU 编译错误有独立检测，异常时自动移除磨损着色器扩展，恢复基础物理材质。
- 当前是实时 PBR 渲染：环境间接光为预过滤近似，不是路径追踪或完整多次光线反弹；形变和机械动画仍为可视化演示，不包含刚体碰撞或材料力学求解。
- `vendor/three.min.js` 使用同版本官方未压缩源码，保留原文件名以兼容页面引用。来源：<https://unpkg.com/three@0.160.0/build/three.js>。
- 在项目目录执行 `node .tools/verify-model.cjs`，可检查物理材质、线性 HDR 数据、阴影配置、曝光范围、着色器降级、几何恢复、组件聚焦及四种动画。这是无需浏览器的逻辑检查，实际画面需在支持 WebGL 的浏览器中查看。
